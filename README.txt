XX Code

仓库地址
https://github.com/sklngbls/coding-agent-project.git

项目简介
XX Code 是一个使用 OpenAI 兼容 Chat Completions 接口的轻量编程智能体。
它可以在指定工作区中根据自然语言任务完成文件读取、代码生成、文本修改和命令执行，并支持连续会话。

运行方法
1. 安装 Python 3.11 或更高版本。
2. 在项目目录创建虚拟环境并安装依赖：
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   python -m pip install -e .
3. 在项目目录创建未入库的 .env 文件，填写：
   LLM_API_KEY=你的API密钥
   LLM_BASE_URL=https://服务商提供的API根地址
   LLM_MODEL=模型名称
   URL 路径以服务商文档为准，可能包含或不包含 /v1。
4. 启动程序：
   coding-agent --workspace "工作区路径" "要完成的编程任务"
   也可以运行 xx code，按提示选择工作区和会话。

设计说明
程序由命令行入口、Agent 循环、模型适配、本地工具和会话存储等模块组成。模型根据任务决定下一步操作，Agent 调用对应工具并将结果返回模型，循环直到任务完成或达到限制。

运行流程
程序读取工作区和历史会话，将用户任务与工具定义发送给模型；模型返回下一步操作后，本地工具执行并回传结果，循环直到得到最终回答。

特色功能
- 支持多轮模型与工具交互，可读写文件、精确替换文本和执行命令。
- 文件路径限制在指定工作区内，命令使用结构化参数执行，并设置超时和输出限制。
- 修改文件和执行命令前可显示预览并请求确认。
- 支持连续会话、会话标题、重命名、删除、本地持久化和历史摘要。
- 对模型错误和工具错误进行结构化处理，并对 API Key 做脱敏。
